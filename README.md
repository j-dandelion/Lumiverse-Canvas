# 🖌️ Canvas
Convenient tweaks and shortcuts to enhance your Lumiverse UI! More at your fingertips: spend less time hunting for the right tab and going in and out of settings.

🔧 Everything is optional, toggle each behavior

🎨 Faithful to the vanilla Lumiverse UI and theme system 

(If you have custom CSS it might need some adjusting. See `docs/custom-css.md`) 

## Features included so far
- **Drag to resize panels**: Drag sidebar/drawer panel edges to resize them
- **Center the chat in the visible area**: Prevent panels from covering chat
- **Second drawer**: Add a second sidebar drawer, move tabs between drawers freely (right click tab -> click move, or enable drag and drop in Canvas settings)
- **Tabs along screen edge**: Move tab buttons to the other side of the drawer panel
- **Taskbar mode**: *pin* the tab buttons along the screen edge - only the panel opens and closes (slide on Sides, a rail bloom on Top/Bottom). This means you can open a specific tab at any time without opening the drawer first
- **Drag and drop tabs**: Drag and drop tabs to rearrange them without having to open the "Configure Tabs" menu
- **Drawers on top/bottom**: Pin the tab strips to the top or bottom screen edge, with a draggable split between the two drawers
- **"Configure Tabs" menu expansion**: Allows customizing tab layout for both single-drawer and dual-drawer mode, all in one place
- **Hide drawer open/close buttons** setting: They're a bit redundant in taskbar mode, so you have the option to hide them
- **Slash commands**: `/select-all`, `/select 10-40`, `/newchat`, `/persona`, more coming soon. Suggestion and autocomplete system. Focused on performance
